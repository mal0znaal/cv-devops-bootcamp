# Проверь обязательный аргумент

Создай исполняемый `~/lab29/require-file.sh`, который принимает путь к файлу. Если аргумент не передан или файла нет — возвращает ненулевой статус. Если файл есть — пишет `ok` и возвращает 0.

Проверь три случая самостоятельно: без аргумента, с отсутствующим файлом, с существующим файлом.

---

Проверка оценивает итоговое состояние учебной машины.
