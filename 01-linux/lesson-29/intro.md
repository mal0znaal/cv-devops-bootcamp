# 29. Надёжный Bash: условия, коды ошибок, pipefail, trap

**Время:** ориентировочно 45–90 минут. Отдельные лабораторные создают отдельные Ubuntu VM.

## Успех надо доказывать кодом завершения

Команда обычно возвращает 0 при успехе и ненулевой статус при ином исходе. `if command; then ... fi` непосредственно проверяет этот статус. `test -f file` или `[[ -f file ]]` проверяет существование обычного файла, а `[[ -d dir ]]` — каталога. `if` в Bash — не обязательно сравнение булевых Python-значений.

## Почему `set -euo pipefail` полезен, но не волшебный

`-e` старается прерывать выполнение при неперехваченной ошибке, но имеет **исключения** для условий, частей `&&`/`||`, pipelines и контекстов функций. `-u` считает обращение к неустановленной переменной ошибкой. `pipefail` делает статусом pipeline ненулевой статус правого наиболее позднего провалившегося элемента. Не верь, что это делает скрипт автоматически корректным.

## Надёжная обработка входных данных

`"${1:?usage: script path}"` требует аргумент с сообщением об ошибке; `"${1:-default}"` подставляет значение при пустом/отсутствующем. `[[ -f "$file" ]]` использует кавычки даже если Bash внутри `[[...]]` меньше подвержен splitting. Это упрощает переносимость привычек в остальные команды.

## trap и уборка

`trap 'rm -f "$tmp"' EXIT` регистрирует действие при выходе Bash-скрипта. Для временных файлов лучше использовать `mktemp`, а не фиксированное `/tmp/test`, чтобы избегать конфликтов и небезопасных подмен. Сигналы, завершение и ловушки позволяют корректно убирать ресурсы после ошибки.

## Реальная проблема pipeline

`grep ERROR file | wc -l` при отсутствии совпадений может вернуть статус 0 от `wc`, даже если `grep` вернул 1. С `pipefail` pipeline получает ненулевой результат. Но для `grep` код 1 может означать **не ошибка**, а нормальное отсутствие совпадений — значит, нужна продуманная обработка.

**Здесь нельзя срезать углы:** не лепи `|| true` к каждой падающей команде. Сначала выясни её код завершения и почему этот исход допустим или недопустим. [Bash set](https://www.gnu.org/software/bash/manual/html_node/The-Set-Builtin.html).
