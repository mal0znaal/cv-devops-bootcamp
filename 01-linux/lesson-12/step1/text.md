# Частотность HTTP-кодов

Создай `~/lab12/codes.txt` с шестью строками: `200`, `500`, `200`, `404`, `500`, `200`.

С помощью `sort | uniq -c` узнай количество каждого кода. Запиши в `~/lab12/report.txt` три строки `200=3`, `404=1`, `500=2`. Порядок строк значения не имеет.
