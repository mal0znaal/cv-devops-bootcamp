# 31. Обработка логов по-взрослому: sed, awk, regex

**Время:** ориентировочно 45–90 минут. Отдельные лабораторные создают отдельные Ubuntu VM.

## В чём разница между grep, sed и awk

`grep` прежде всего выбирает строки. `sed` — потоковый редактор: может печатать, отбирать, заменять фрагменты. `awk` — язык обработки записей и полей с переменными, арифметикой и условиями. Начать нужно с простого: `sed 's/ERROR/WARN/' file` заменяет первое совпадение в каждой строке только в **выводе**, а не в исходном файле.

## awk и поля

По умолчанию awk делит строку на поля по пробельным последовательностям. `$1` — первое поле, `$2` — второе, `$0` — вся строка. `awk '$2 == 500 {count++} END {print count+0}'` посчитает подходящие записи. В shell-коде программу awk обычно берут в **одинарные кавычки**, чтобы Bash не раскрыл `$2` вместо awk.

## Почему `sed -i` опасен

`-i` изменяет исходный файл на месте (семантика зависит от реализации). Неправильная замена может разрушить конфигурацию. Сначала попробуй преобразование без `-i`, сравни вывод через `diff`, используй резервные копии или версионирование.

## Регулярные выражения не одинаковы повсюду

`grep -E` и `sed -E` поддерживают extended regex, Bash glob использует другой синтаксис, Python `re` добавляет свои возможности. Не переноси привычки между инструментами без проверки документации.

## Когда выбрать Python

Для одноразового подсчёта двух полей awk прекрасен. Для сложных JSON-логов, многострочных stack trace, CSV с кавычками или готового проекта на Python часто разумнее использовать Python и его библиотеки. Критерий — корректность и сопровождаемость, а не минимальная длина команды.

**Не срезай угол:** перед `sed -i` всегда проверь преобразование на stdout. [GNU sed](https://www.gnu.org/software/sed/manual/sed.html), [GNU awk](https://www.gnu.org/software/gawk/manual/gawk.html).
