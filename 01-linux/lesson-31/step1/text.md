# Создай метрики из псевдологов

Создай `~/lab31/access.log` с записями:

```text
GET 200
POST 500
GET 200
GET 404
POST 500
```

Используя `awk` (или комбинацию текстовых утилит), запиши в `~/lab31/summary.txt` строки `200=2`, `404=1`, `500=2`.

**Не срезай угол:** попробуй сначала `awk '{print $2}'` и объясни, почему кавычки вокруг awk-программы необходимы.
