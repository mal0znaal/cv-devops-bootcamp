# Карта системы

Исследуй `/etc/os-release`, `/proc/meminfo`, `/dev/null`, `/var/log`, `/usr/bin`.

Создай `~/lab14/map.txt` из пяти строк в любом порядке, в формате `config=/etc`, `logs=/var`, `processes=/proc`, `devices=/dev`, `programs=/usr`. Не редактируй системные файлы.

<details><summary>Подсказка</summary>Каждая строка связывает понятие с каталогом. Их можно записать через nano.</details>
