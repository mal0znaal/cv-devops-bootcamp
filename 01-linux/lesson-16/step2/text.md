# Разреши выполнять свой скрипт

Создай `~/lab16/run.sh`:

```bash
#!/usr/bin/env bash
printf 'ready\n'
```

Сделай его исполняемым для владельца, но не для других (`chmod 700`). Запусти через `~/lab16/run.sh`.

**Не срезай угол:** объясни, чем отличается `bash run.sh` от `./run.sh` при отсутствии бита `x`.

---

Нажимай CHECK после собственной проверки результата.
