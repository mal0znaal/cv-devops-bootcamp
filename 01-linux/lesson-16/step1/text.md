# Настрой строгие права конфигурации

Создай `~/lab16/config.env` с текстом `TOKEN=dummy-not-secret` и установи **режим 600**, то есть читать и изменять может только владелец.

Проверь `ls -l` и `stat -c '%a' ~/lab16/config.env`. Почему этот режим лучше, чем 777, для файла с секретами?
