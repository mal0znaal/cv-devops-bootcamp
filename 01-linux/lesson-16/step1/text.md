# Настрой строгие права конфигурации

Создай `~/lab16/config.env` с текстом `TOKEN=dummy-not-secret` и установи **режим 600**, то есть читать и изменять может только владелец.

Проверь `ls -l` и `stat -c '%a' ~/lab16/config.env`. Почему этот режим лучше, чем 777, для файла с секретами?

## Проверь цифровые и символьные права

Сначала сделай `chmod 600` на тестовом файле, затем посмотри `stat -c '%a %A'`. Шесть означает `rw-` для владельца, ноль — отсутствие прав у группы и остальных. Вопрос: почему мы не ставим `700`? Обычному конфигурационному файлу не нужна возможность запуска.

Если учебный терминал работает под root, помни, что такой пользователь способен обходить обычные проверки: не делай вывод «права работают» только по успешному `cat` от root.

**Где не срезать углы:** не изменяй владельца и не применяй `sudo` ради этой задачи. Созданный тобой файл уже доступен для управления.
