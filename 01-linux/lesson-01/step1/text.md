## Исследование перед созданием файла

Сначала выполни три команды и **запиши отдельно их ответы**:

~~~bash
uname -r
cat /etc/os-release
ps -p 1 -o pid,comm,args
~~~

Ответ `uname -r` относится к ядру. `NAME` и `VERSION_ID` из `os-release` — к дистрибутиву. `PID 1` — к первому пользовательскому процессу видимого PID namespace. Эти ответы описывают разные части системы, поэтому нельзя подставить версию Ubuntu вместо release ядра.

Проверь через `uname --help`, чем `-r` отличается от `-m`. Если `ps -p 1` показывает не systemd, выясни, не работаешь ли ты в контейнерном окружении.

**В notes для себя ответь:** какую именно границу пересекает Python при системном вызове? Файл `kernel.txt` нужен для CHECK, но его содержимое имеет смысл только после ответа на этот вопрос.

**Где не срезать углы:** не копируй чужую строку версии ядра. Даже у двух Ubuntu одной версии ядра могут различаться.
