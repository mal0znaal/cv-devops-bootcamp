# Найди версию работающего ядра

Выполни по одной команде:

```bash
uname -r
cat /etc/os-release
ps -p 1 -o pid,comm,args
```

Сопоставь результаты: `uname` спрашивает сведения о ядре; `os-release` описывает дистрибутив; `ps` показывает процесс PID 1 в видимом пространстве процессов. Это три разных объекта.

Создай каталог `~/lab01` командой `mkdir -p ~/lab01`. Флаг `-p` означает создание отсутствующих родительских каталогов, и он принадлежит именно команде `mkdir`. Затем открой `nano ~/lab01/kernel.txt` и введи точную строку из `uname -r`.

В `nano` сохранение — **Ctrl+O**, подтверждение имени — **Enter**, выход — **Ctrl+X**. Проверь записанное:

```bash
cat ~/lab01/kernel.txt
```

Затем нажми CHECK.

**Не срезай углы:** сравни `uname -r` и номер Ubuntu в `/etc/os-release`; объясни, почему их нельзя подставить друг вместо друга. Перенаправления `>` ещё не проходили — редактора достаточно.
