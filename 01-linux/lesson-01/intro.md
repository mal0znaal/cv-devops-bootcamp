# Урок 1: Linux: ядро, дистрибутив, shell и загрузка

**Время:** 40–60 минут. Это ориентир, а не ограничение. Сессия Killercoda временная, и лабораторная запускается в новой машине.

## Linux — это не терминал

**Ядро Linux** управляет памятью, процессами, файловыми системами, сетью и устройствами. **Дистрибутив** Ubuntu объединяет ядро, системные утилиты, библиотеки, конфигурацию и пакетный менеджер. **Shell** Bash разбирает написанную тобой командную строку. **Терминал** лишь предоставляет интерфейс ввода и вывода. Это четыре разных компонента.

## Как работает приложение

Твоё приложение Python работает в пользовательском пространстве (user space). Когда оно хочет открыть файл, отправить пакет или создать процесс, оно обращается к ядру через системные вызовы (часто через стандартные библиотеки). Ядро проверяет права и распределяет ресурсы. Поэтому CUDA-драйвер для NVIDIA и Python-пакет torch относятся к разным слоям системы, хотя вместе обеспечивают выполнение модели.

## Что запускается при загрузке

Упрощённая цепочка: firmware UEFI/BIOS → загрузчик → ядро → первый пользовательский процесс (обычно systemd) → службы и пользовательские сессии. На Linux есть множество реализаций этой цепочки; не привязывай понятие ядра к конкретной init-системе. Мы изучим PID 1 в теме процессов.

## Увидеть всё своими глазами

`uname -r` показывает релиз ядра. `/etc/os-release` описывает дистрибутив. `ps -p 1 -o comm=` показывает имя процесса PID 1. Это не взаимозаменяемые ответы! `whoami` отвечает, от имени какого пользователя выполняется shell.

## Что важно понять

Версия Ubuntu и версия Linux kernel не обязаны совпадать по календарю. Установленный пакет Python никак автоматически не равен ядру. Bash можно заменить на другой shell, не меняя ядро. А Docker-контейнеры используют ядро хоста — эта связь потом объяснит множество проблем с контейнеризацией.
