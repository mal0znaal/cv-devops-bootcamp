# Определи дистрибутив независимо от ядра

Открой `/etc/os-release` через `cat` и найди три поля: `NAME`, `ID`, `PRETTY_NAME`. Они похожи, но не идентичны. В файл `~/lab01/distribution.txt` запиши **только значение NAME**, без окружающих кавычек.

Проверь через `cat ~/lab01/distribution.txt` и сравни с исходным системным файлом.

Теперь исследуй две команды:

```bash
type -a cat
type -a cd
```

`cat` обычно запускается как отдельная программа, `cd` меняет состояние текущего Bash, поэтому реализована как встроенная команда. Ни та ни другая не является ядром Linux.
