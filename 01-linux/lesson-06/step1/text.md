# Скопируй файл с пробелом в имени

Создай каталог `~/lab06`. В нём файл `model weights.txt` с единственной строкой `yolo`. Сделай копию в `backup.txt`, а оригинал **переименуй** в `model-v1.txt`.

Проверь, что два новых файла содержат `yolo`, а файл со старым именем отсутствует. Используй кавычки, а не заменяй пробел подчёркиванием.

<details><summary>Подсказка</summary>Команды `cp 'model weights.txt' backup.txt`, затем `mv 'model weights.txt' model-v1.txt` при нахождении в нужном каталоге.</details>
