# Удали только временные данные

Создай `~/lab06/remove.tmp` и затем удали **ровно этот файл**. Добавь `~/lab06/safe.txt` со строкой `safe`.

Никакие рекурсивные флаги не нужны. Перед удалением проверь путь через `pwd`.

**Не срезай углы:** не пользуйся `rm -rf`, даже если так кажется быстрее.
