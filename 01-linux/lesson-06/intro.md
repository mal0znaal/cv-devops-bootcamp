# Урок 6. Создание, копирование, перемещение, удаление файлов

**Ориентир:** 45–65 минут. Лабораторная открывает новую временную Ubuntu VM. Не изменяй ничего за пределами указанных тестовых путей.

## Файл не равен его имени

В файловой системе имя — запись в каталоге, которая связывает человеческий путь с объектом. `touch` создаёт пустой файл либо обновляет время доступа/модификации, `cp` копирует содержимое, `mv` переименовывает или перемещает, `rm` удаляет связь с именем. `rm` не отправляет объект в корзину; восстановить данные может быть трудно или невозможно.

## Почему `mv` и `cp` не близнецы

`cp source target` оставляет исходник и создаёт новый файл. Если исходный и целевой путь на одной файловой системе, `mv` обычно меняет запись каталога (rename). При перемещении между разными файловыми системами может понадобиться физическая копия с последующим удалением. Поэтому не думай, что любой `mv` атомарен при любых обстоятельствах.

## Работа с каталогами

`cp -r dir target` рекурсивно копирует дерево; поведение ссылок зависит от конкретных ключей. `rm dir` без опции рекурсии каталог не удаляет. `rmdir` удаляет только пустые каталоги. `rm -r` обходит поддерево и удаляет файлы: абсолютно не подходит для экспериментов с незнакомыми абсолютными путями.

## Пробелы и спецсимволы

Файловая система допускает имя `model weights.pt`. Но shell разбивает незакавыченную строку по пробелам. Используй кавычки (`'model weights.pt'`) или экранирование. В следующих уроках отдельно разберём эти правила. Опасность `rm -rf` не только в ключах — проблема может быть в неверно раскрытом пути или переменной.

## Безопасный алгоритм

Сначала `pwd`, потом `ls -la` или `find`, затем операция. Для опасных действий проверяй точный путь, работай с копией. В настоящих проектах сначала делай резервную копию, затем изменяй исходные данные.

**Не срезай углы:** сегодня используй `rm` только внутри `~/lab06`, без `-rf`, и никогда не подставляй переменную, значение которой не проверил.
