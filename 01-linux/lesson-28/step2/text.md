# Скрипт для подготовки структуры проекта

Напиши исполняемый `~/lab28/mkproject.sh`, которому передаётся путь до будущего проекта как **один аргумент**. Он создаёт внутри него `models`, `logs` и `data`. Используй `mkdir -p` и кавычки вокруг пути.

**Не срезай углы:** тестируй вызов с путём, содержащим пробел, например `~/lab28/my cv project`. При повторном запуске скрипт должен не ломаться.
