# Напиши скрипт с аргументом

Создай исполняемый `~/lab28/greet.sh`, принимающий **первый аргумент** и печатающий `hello, NAME` (например, `./greet.sh cv` → `hello, cv`).

Подсказка: `#!/usr/bin/env bash`, `printf 'hello, %s\n' "$1"`. Затем попробуй имя `CV engineer` в кавычках.
