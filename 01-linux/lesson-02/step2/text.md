# Найди два флага по справке

Открой `ls --help`. Найди короткую опцию для показа скрытых файлов и короткую опцию для подробного списка.

В файл `~/lab02/options.txt` запиши **две строки**: в первой опция скрытых файлов, во второй — длинного формата. Не запрашивай готовый ответ: найти флаги в help — именно цель занятия.

---

**CHECK:** проверяется состояние системы, а не конкретная последовательность команд.

## Прочитай справку и проверь оба флага

`ls --help` содержит описание `-a` и `-l`. Но недостаточно переписать две буквы. Создай временный каталог с `hello.txt` и `.hidden.txt`. Сравни `ls`, `ls -a` и `ls -la`: какое свойство вывода меняется после каждого флага?

**Контрольный вопрос:** меняет ли `ls -a` реальные права на скрытый файл? Нет — проверь через `stat` и объясни почему. В CHECK нужны только флаги, но проверять собственное понимание придётся самому.
