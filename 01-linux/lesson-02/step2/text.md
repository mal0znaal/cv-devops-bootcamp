# Найди два флага самостоятельно

Открой `ls --help`. Тебе нужны две короткие опции: одна добавляет в список файлы, имена которых начинаются с точки, другая выводит подробные сведения о файлах.

Прежде чем записывать ответ, проведи эксперимент:

```bash
mkdir -p ~/lab02/experiment
cd ~/lab02/experiment
touch visible.txt .hidden.txt
ls
```

Применяй найденные опции по одной, затем вместе. Сравни четыре результата: обычный список, список со скрытым файлом, подробный список и подробный список со скрытым файлом. Возвращаться из каталога можно командой `cd ~`.

В `~/lab02/options.txt` запиши две строки: сначала короткую опцию для скрытых имён, затем — для подробного формата.

**Вопрос после эксперимента:** меняется ли содержимое каталога после `ls` с этими опциями? Или меняется только отображение?

**Не срезай углы:** не ищи готовые две буквы в соседних уроках. Цель этого задания — извлечь значение опций из собственной версии справки и проверить его в терминале.
