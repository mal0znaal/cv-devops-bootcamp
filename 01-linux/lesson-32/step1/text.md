# Собери минимальный безопасный диагностический отчёт

Создай исполняемый Bash-скрипт `~/lab32/report.sh`, который при запуске выводит четыре строки с префиксами `kernel=`, `cpu=`, `memory=`, `filesystem=`.

Значения должны браться из **живой системы**: `uname -r`, `nproc`, поле MemAvailable из `/proc/meminfo` (допускается значение с единицей измерения), тип корневой ФС из `findmnt -n -o FSTYPE /`.

Сохрани вывод этого скрипта в `~/lab32/diagnostics.txt`. Утилиты могут отличаться по версии, но имена полей должны быть фиксированными.

**Не срезай угол:** не вставляй случайные числа в скрипт. Проверка запустит его ещё раз и сопоставит kernel и cpu с текущей машиной.
