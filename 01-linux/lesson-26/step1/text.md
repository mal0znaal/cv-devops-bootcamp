# Создай безопасную учебную пару ключей

Прочти `man ssh-keygen` (если man установлен) или [документацию OpenSSH](https://man.openbsd.org/ssh-keygen). Не используй `ssh-keygen -h` как флаг справки — у этой программы `-h` имеет другое значение.

Создай **отдельную учебную** пару Ed25519: `~/lab26/id_ed25519` и `~/lab26/id_ed25519.pub`. Не используй настоящие рабочие ключи.

Для упражнения можно оставить passphrase пустой, но **только на одноразовой учебной VM**. В реальных рабочих ситуациях приватные ключи обычно защищают надёжной парольной фразой.

<details><summary>Подсказка — открыть только после попытки</summary>Создай папку `mkdir -p ~/lab26`, затем `ssh-keygen -t ed25519 -f ~/lab26/id_ed25519 -N ''`. Не копируй этот шаблон для production-ключей бездумно.</details>
