# Создай безопасную учебную пару ключей

Проверь `ssh-keygen -h` и `man ssh-keygen` (если man установлен). Создай **отдельную** тестовую пару Ed25519 `~/lab26/id_ed25519` и `~/lab26/id_ed25519.pub`. Не используй настоящие рабочие ключи.

Для упражнения можно оставить passphrase пустой, но **только на одноразовой учебной машине**. В реальной жизни приватные ключи обычно защищают надёжной парольной фразой.

<details><summary>Подсказка</summary>`mkdir -p ~/lab26`, затем `ssh-keygen -t ed25519 -f ~/lab26/id_ed25519 -N ''`. Не копируй этот шаблон для production-ключей бездумно.</details>
