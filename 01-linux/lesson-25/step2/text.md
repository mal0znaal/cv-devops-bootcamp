# Сделай честный healthcheck

Создай исполняемый файл `~/lab25/health.sh`. Он должен выполнять **настоящий** HTTP-запрос через `curl -fsS` на `127.0.0.1:8765` и возвращать код 0 при успехе.

**Не срезай угол:** скрипт с голым `exit 0` — фальшивый healthcheck. Прочти опцию `--fail` в `curl --help`.

---

Проверка оценивает итоговое состояние учебной машины.
