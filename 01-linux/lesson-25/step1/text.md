# Подними локальный HTTP

Создай в `~/lab25` файл `index.html` со строкой `cv-online`. Запусти `python3 -m http.server 8765 --bind 127.0.0.1 --directory ~/lab25 &`.

Посмотри `ss -ltnp` и вызови `curl -fsS http://127.0.0.1:8765/`. Процесс должен оставаться жив до CHECK.
