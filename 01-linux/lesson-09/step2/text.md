# Защити путь с пробелами

Создай в `~/lab09` файл `my model.pt` со строкой `weights`. Скопируй его в `copied.pt`, не меняя исходное имя. Используй кавычки.

Потренируйся печатать значение shell-переменной без потери пробелов: `name='my model.pt'`, затем `printf '%s\n' "$name"`.
