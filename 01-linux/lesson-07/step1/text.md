# Собери маленький событийный лог

Создай `~/lab07/events.log` с пятью строками в точном порядке:

```text
boot
load-model
ready
request
shutdown
```

Прочитай его через `cat`, посмотри первые две строки через `head -n 2`, последние две через `tail -n 2`. Сколько строк показывает `wc -l`?

---

CHECK проверяет результат. При неудаче прочитай ошибку и исследуй причину.
