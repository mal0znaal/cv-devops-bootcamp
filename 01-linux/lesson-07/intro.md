# Урок 7. Чтение текста: cat, less, head, tail, wc

**Ориентир:** 45–65 минут. Лабораторная открывает новую временную Ubuntu VM. Не изменяй ничего за пределами указанных тестовых путей.

## Чтение не равно редактированию

`cat` объединяет файлы и печатает их содержимое в stdout; `nano` и `vim` — интерактивные редакторы, меняющие файл. `less` — просмотрщик: в большом логе можно искать `/error`, листать страницами и выйти клавишей `q`. Не печатай весь гигабайтный лог в терминал: такой вывод не помогает диагностике.

## Быстрый доступ к фрагменту

`head -n 3 file` — первые три строки, `tail -n 2 file` — последние две. `tail -f` не просто показывает конец, а **продолжает следить** за добавляемыми строками — полезно при наблюдении за логом. Остановить слежение можно Ctrl+C: это сигнал, а не «сломанный терминал».

## Что означает строка файла

Текст — последовательность байтов. При UTF-8 один символ может занимать несколько байтов. Обычно строка заканчивается символом LF (`\n`), который в файле занимает один байт. `wc -l` считает именно разделители новой строки, поэтому файл с текстом без финального LF может показать неожиданное число.

## Сравни счётчики

`wc -c` считает байты, `wc -m` — символы с учётом локали, `wc -l` — переводы строк. В Linux и Windows различаются соглашения LF и CRLF; если Bash-скрипт сохранён с Windows-переводами строк, можно получить ошибку с `^M`. Это не магия — лишний байт `\r`.
