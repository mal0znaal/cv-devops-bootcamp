# CV DevOps Bootcamp

**Бесплатный практический DevOps + MLOps курс для инженера компьютерного зрения.** Учимся в настоящем Linux-терминале Killercoda, а не запоминаем оторванные от работы команды.

## Модуль 01 — Linux

Все 34 лабораторные и проверки записаны в GitHub. Автоматические проверки контролируют структуру сценариев и синтаксис Bash, но **прохождение всех лабораторных в настоящих Killercoda VM ещё не подтверждено**. Если в окружении возникнет ошибка, её нужно отдельно воспроизвести и исправить.

[**Открыть 34 урока Linux**](./01-linux/README.md) · [**Структура интерактивного курса**](./01-linux/structure.json)

От устройства ядра и Bash до файловой системы, прав, процессов, systemd, пакетов, дисков, SSH, сети, скриптов, документации и итоговой диагностики сломанного CV-сервиса.

**Как проходить:**
1. Открой раздел «Модуль 01» на странице автора Killercoda, подключённого к этому репозиторию.
2. Выбирай уроки по порядку: 01 → 34. Каждый открывает **новую временную Ubuntu VM**.
3. Читай теорию, запускай эксперименты и только потом решай задания.
4. Если застрял, сначала ищи ответ в `--help`, `help` и `man`. Затем открывай подсказки.
5. Нажимай CHECK для проверки фактического результата. Не переписывай команду из подсказки без понимания.
6. Для двух последних практических миссий не ищи готовое исправление — работай по диагностическим признакам.

> На бесплатном тарифе Killercoda одна лабораторная работает максимум **1 час**, после чего VM пересоздаётся. Если лекция длинная, сначала прочитай `intro.md` на GitHub, а потом открывай терминал для опытов и CHECK. Особенно это относится к [уроку 01](./01-linux/lesson-01/intro.md). Не сохраняй в учебной VM личные токены и реальные секреты.

## Правило «не срезать углы»

Цель — научиться находить причины и читать документацию, а не имитировать выполнение заданий. В рабочих окружениях **никогда не** применять случайные `rm -rf`, `chmod 777`, `sudo` или опасные команды дискового администрирования.

1. **Linux** — 34 урока (готово)
2. Сети и диагностика TCP/IP, DNS, маршрутизации
3. Git и командная разработка
4. Docker: образы, контейнеры, слои, безопасность
5. Docker Compose и эксплуатация стека
6. Nginx, reverse proxy и HTTPS
7. GitLab CI/CD и деплой
8. PostgreSQL: роли, бэкапы, восстановление
9. **Redis:** структуры, persistence, репликация, Sentinel
10. **Prometheus + Grafana:** exporters, метрики, PromQL, dashboards, алерты
11. Ansible и Terraform
12. Kubernetes: основы, сеть, хранилище, Helm
13. Kubernetes: эксплуатация сервисов и мониторинг
14. **MLOps:** GPU Docker, CUDA, PyTorch, упаковка inference, VRAM, бенчмарки и развёртывание CV-сервисов

Следующие разделы — **план**, ещё не опубликованные лабораторные. Не путать с готовым модулем Linux.

## Техническая структура

Каждый сценарий содержит `index.json`, `intro.md`, отдельные шаги `stepN/text.md` и `stepN/verify.sh`, затем `finish.md`. Финальные инциденты дополнительно создают подготовленное окружение через `background.sh`.
