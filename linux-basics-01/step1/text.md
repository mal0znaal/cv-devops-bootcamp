# Создай файл в Linux

**Задача:** в домашней директории создай папку `bootcamp`, а в ней файл `hello.txt` с единственной строкой `linux-ready`.

Условия проверки:

- Существует файл `~/bootcamp/hello.txt`.
- Файл содержит строку `linux-ready`.

Можно воспользоваться `mkdir`, `printf` и перенаправлением вывода `>`.

<details><summary>Подсказка: пример команд</summary>

```bash
mkdir -p ~/bootcamp
printf 'linux-ready\n' > ~/bootcamp/hello.txt
```

</details>

Когда закончишь, нажми **CHECK** — результат проверит Bash-скрипт. Этот шаг нужен для проверки интеграции; следующие задачи курса будут существенно интереснее.
