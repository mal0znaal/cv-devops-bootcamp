# Linux · Лабораторная №1

Добро пожаловать в **CV DevOps Bootcamp**! Это тестовая лабораторная, которая проверяет, что GitHub → Killercoda работает, а команды действительно исполняются в отдельной Linux-машине.

**Что получишь:** доступ к Ubuntu-терминалу, первое задание и кнопку **CHECK** для автоматической проверки результата.

Нажми **START**, чтобы перейти к заданию.
